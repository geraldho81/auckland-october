# Auckland, October (dates TBA)

A single-page itinerary site for Gerald Ho trip to Auckland / Tamaki Makaurau. Frontend only. No database, no auth, no CMS.

Dates are still TBA, sometime in October.

## How to run locally

```
npm install && npm run dev
```

Open http://localhost:3000

## Build

```
npm run build
```

## Stack

Next.js App Router, TypeScript, Tailwind CSS, next/image, lucide-react, Fraunces and Manrope.
